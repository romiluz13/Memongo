# Reference

Lookup pages for configuration, shared types, and dependencies. See `droid-wiki/overview/architecture.md` for how these pieces fit together and `droid-wiki/overview/getting-started.md` for a guided setup.

- [Configuration](configuration.md) — every environment variable and the optional `~/.memongo/memongo.json` config file, grouped by category, with precedence rules.
- [Data models](data-models.md) — the shared TypeScript types for scope, search, trust, lifecycle, and errors that other pages link to instead of restating.
- [Dependencies](dependencies.md) — core runtime packages, the root `overrides` block, external services, and build tooling.
