# Memongo 2.2.3

This patch preserves explicitly requested scalar or binary quantization during
MongoDB automatic embedding index setup. If MongoDB rejects that setting,
index setup reports the rejection instead of retrying without quantization.
The same rule applies when updating an existing index; a rejected update must
not become an already-exists success.

The existing `none` setting continues to omit the quantization property and
uses the server default. It does not explicitly request full-precision float
vectors. Numeric MongoDB Search vector fields retain their existing behavior.
No new quantization modes or global default changes are included.

## Validation scope

Focused offline regressions cover rejected create and update requests, the
supported vector lanes, and accepted omitted, none, scalar and binary settings.
These tests use an external storage adapter; they do not establish Atlas index
acceptance, effective quantization, retrieval quality or performance. Release
verification must separately check the active Atlas definitions and native text
retrieval before qualification. Package and image publication do not establish
an operational API host.
