## Notes on PARTIAL / ambiguous cases

- **RET-02** is classified OPEN because the defect as described is fully intact: explicit bounds never prefilter any lane, and the corrective/widened pass range still never reaches V2 (the pass-level `timeRange` is destructured and dropped in the manager callback). The one change since the audit — `intent.timeRange` reaching the planner — was already true at audit time and is only a scoring/classification signal.
- **RET-05**: the locator half of the finding (identity collapse) was repaired by the WS-15 typed `from-to-type` locator. The P1 core — a false rendered proposition (`root relation neighbor` regardless of actual edge direction) — is byte-identical to the audited code. Any repair must change snippet rendering, not locators.
- **RET-06**: the bitemporal arms (WS-15 C-026) close the stale-evidence half of the finding for direct searchV2 callers; the tenant-identity half (no scope/scopeRef in the default filter, no validation that a custom filter cannot widen identity) is untouched.
- **RET-10**: the guards landed only on active-slate *structured* reads. Every other hydration surface named in the finding (recent events, episode summary, procedures slate, session expansion) still lacks lifecycle predicates.
- **RET-11**: key identity is much stronger (P2.4), but the finding's primary trigger — cached bodies outliving constituent expiry — has no fix: entry `expiresAt` is still `now + ttlSec` and exact hits are not revalidated against source validity. Enabling the detailed cache (RET-12) must not precede this.
- **RET-13**: WS-11/WS-12 made *budget-denied* and *rerank-skipped/failed* distinguishable, which covers one clause of the metadata complaint. Lane failure semantics (inner catch → `[]` → recorded as not-executed) and strict-mode bypass are unchanged; benchmark strict mode can still succeed with silently missing subsystems.
- **RET-16**: WS-10/C-017 added real accounting, but it remains per-V2-invocation; a detailed multi-pass request still gets N independent budgets plus uncharged retries and the uncharged KB `$text` fallback.
- **RET-17**: still library-only (no production invocation found outside `internal-barrel.ts` and tests), so "P1 if invoked" stands. Expiry handling is fixed; namespace identity (scope-less read filter and path key) and stale-tail cleanup are not.
- **RET-19**: remaining nondeterminism is narrowed to planner lane-freshness scoring and lane-coverage timestamps; the recall TTL wall-clock divergence the audit cited is repaired (both recall paths now filter on `asOf`).
