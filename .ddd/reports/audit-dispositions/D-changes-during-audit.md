## Notes

- **D1**: The core defect (denial blurred into "no memories" and dropped at executor/manager) is repaired end to end by WS-11/WS-12, including stopping corrective passes and charging the legacy fallback its own token. Two residuals keep this PARTIAL rather than FIXED: (1) the query-cache semantic probe still executes (and embeds) before admission is consumed, so exhausted traffic still pays provider work — the audit's "provider-consuming cache work participates in the same policy" acceptance is unmet; (2) the benchmark harness has no typed-denial consumption, so the audit's "verify denied requests with actual public calls" acceptance is met only in mocked API tests (`apps/api/src/app.segment3.test.ts:1730-1756`), not in benchmarks. Process-local bucket scope is now an explicitly documented design choice (`mongodb-search-admission.ts:127-130`); multiprocess accounting remains out of scope by design, flagged here for the record.
- **D3**: Predominantly OPEN in substance; classified PARTIAL because the cited provider-test shape defect is repaired and the erasure omission (D4) landed. The "billing-grade" claim still stands in the module header (`mongodb-cost-ledger.ts:14-15`) while the implementation remains lossy best-effort — DW02/DL-03 track the same tension. Note: header cites `docs/cost-model.md`; actual path is `docs/platform/cost-model.md` (doc-path drift, not a finding).
- **D5**: The status-surface half improved (distinct failed/dead-lettered counts), but every guarantee-width defect the finding names — gauge population, one-shot concurrency sampling, fail-zero, per-call/per-instance cap, HTTP 500 mapping — persists verbatim. The new distinct counts do not feed `backlogAlert`.
- **D6**: WS-16 moved the rerank stage under a real remaining-budget deadline, which is the first runtime (non-arithmetic) piece of an end-to-end bound; probe/aggregate composition, retries, and pool checkout remain outside any shared deadline, and the telemetry interpretation defects (sampling probability, denied-vs-served separation in aggregation) are unchanged.
